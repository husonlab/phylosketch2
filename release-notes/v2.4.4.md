# PhyloSketch 2.4.4

## Bug fixes

- **Export Newick** in the export button of the tool bar (previously labelled "Export data...") did nothing. It now
  exports the phylogeny in Newick format, as File > Export > Newick does
- In Move mode, moving a node no longer opens the selection rectangle. This happened on touch screens when the
  finger went down on the edge of a node
- Capturing an image that is unsuitable, because too much of it is dark, is reported as a message that says what
  is wrong with the image, and no longer as an exception in the log

## iPhone and iPad app

- PhyloSketch is also available as an app for iPhone and iPad, see
  <https://husonlab.github.io/mobile-apps/>. Changes that concern the app only are described with each
  update of the app, not here
