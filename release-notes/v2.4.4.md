# PhyloSketch 2.4.4

## Bug fixes

- **Export Newick** in the export button of the tool bar (previously labelled "Export data...") did nothing. It now
  exports the phylogeny in Newick format, as File > Export > Newick does
- In Move mode, moving a node no longer opens the selection rectangle. This happened on touch screens when the
  finger went down on the edge of a node
- Capturing an image that is unsuitable, because too much of it is dark, is reported as a message that says what
  is wrong with the image, and no longer as an exception in the log

## Touch screens (iOS app)

- **Copy Image** copies the image and opens the share sheet, from which it can be saved, so that it does the job
  of Export Image as well; Export Image, which needs a file dialog, is no longer offered. The image no longer has
  an empty area on the right and at the bottom
- **Export Newick** writes the Newick string to a file and opens the share sheet for it
- A node that is held for a moment before it is dragged follows the finger; before, it could be left behind
- The Cancel and Done buttons shown when an image is cropped for capture are readable in the light theme
