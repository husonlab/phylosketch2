# PhyloSketch 2.4.2

## New features

- Copy and export images now uses a tight bounding box
- Suppressing a through node now combines the two edges' values on the new edge: weights are summed, confidences take the minimum, and probabilities are multiplied (if only one edge has a value, that value is used); a value that was displayed on the replaced edges stays displayed on the new edge
