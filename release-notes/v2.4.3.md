# PhyloSketch 2.4.3

## New features

- **Rectilinear Layout** (Layout menu, and the Rectilinear button in the Transform panel, in Edit or Transform mode)
  redraws a tree or network on a grid, as SplitsTree's network view does: all edges become straight lines, running
  horizontally or vertically where possible and diagonally otherwise, with few crossings and room for the labels,
  which are placed away from the edges. The drawing stays where it was, the grid is switched on so that the result
  can be adjusted by hand, and the layout is undone in one step. It takes at most two seconds and does not take the
  position of the root into account; Draw Phylogeny gives back a conventional drawing
- **Use Grid** (View menu, and the Grid toggle in the Transform panel) snaps all nodes to a grid, no two onto the
  same point, so that a drawing can be tidied up by hand; while it is on, dragged nodes move in grid steps.
  Rectangular edges stay rectangular, and the grid spacing is chosen for the drawing, at half the typical edge
  length; a drawing saved on the grid keeps its grid when opened again. Switching the grid on can be undone
- Suppressing a through node now combines the two edges' values on the new edge: weights are summed, confidences take the minimum, and probabilities are multiplied (if only one edge has a value, that value is used); a value that was displayed on the replaced edges stays displayed on the new edge

## Bug fixes

- Dragging a node no longer leaves an incoming straight, rectangular or curved edge short of it: the first step of
  the drag moved a point near the start of such an edge instead of its end
- Nodes can be dragged, and edges drawn, up to 200 pixels beyond the left and top of the drawing, wherever it lies;
  before, a fixed limit near the top-left corner of the canvas silently stopped them there
